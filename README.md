My Python Lab: Interacting with the Operating System
This repository contains my practical exercises for the "Using Python to Interact with the Operating System" module. As an aspiring DevOps Engineer, I am using these scripts to master how Python communicates with a Linux environment (WSL).

🚀 Script Overview: info_os.py
This script programmatically retrieves essential system information using Python's built-in libraries. It demonstrates the ability to:

Identify the Current User: Fetches the username via environment variables.

Determine OS Metadata: Detects whether the script is running on Linux or Windows.

Kernel & Release Tracking: Pulls specific kernel version data (specifically for WSL/Microsoft).

Path Management: Displays the current working directory to ensure correct script execution paths.

🛠️ Usage
To run this script in your Linux/WSL terminal, ensure Python 3 is installed:

Bash

python3 info_os.py
